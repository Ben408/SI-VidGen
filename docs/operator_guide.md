# Operator Guide

## V0 workflow

1. Open the local SI VidGen web UI.
2. Enter the support issue and optional Intacct module.
3. Select **Generate draft**.
4. Follow stage progress in the run panel.
5. Download the generated Higgsfield payload.

Phase 0 uses deterministic placeholder classification and script content. Ollama, XHTML retrieval, and formal review are added in later phases.
